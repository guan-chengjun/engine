# engine

初始环境快照仓库。

本仓库的第一次提交（commit `initial environment snapshot`）代表工作区已配置就绪的状态基线，
后续所有改动都可与该基线对比。

- 组织 / 仓库：`guan-chengjun/engine`
- 快照形式：commit permalink
  `https://github.com/guan-chengjun/engine/commit/<40 位完整 SHA>`

## 目录约定

| 路径 | 用途 |
| --- | --- |
| `README.md` | 仓库说明与基线记录 |
| `.gitignore` | 通用忽略规则 |

## 使用

```bash
git clone https://github.com/guan-chengjun/engine.git
cd engine
```
